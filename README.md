# Car（byd-mini）

一个极简的比亚迪车控界面：按钮自己排，底层借道官方「比亚迪汽车」App 完成操作。
不 root、不逆向蓝牙协议、不需要账号密码。

## 功能

- 主界面 4 个按钮，桌面小部件 2×2 / 4×2（各 5 个按钮）
- 内置动作：解锁、上锁、开后备箱、一键熄火、空调、寻车
- 自定义动作：填「官方 App 里那个按钮的文字」即可，多个写法用逗号分隔
- 点击时用全屏遮罩盖住跳转过程，点完自动回到自己的界面
- 桌面名字 / 图标可在设置里切换（4 名字 × 4 图标）

## 使用前提

1. 手机已安装并登录官方「比亚迪汽车」App（包名 `com.byd.aeri.caranywhere`）
2. 设置 → 无障碍 → **Car** 打开
3. 部分国产 ROM 还要给 Car 开「后台弹出界面」和「显示在其他应用上层」

## 工作原理

1. 自己的界面先截一张图，用 `TYPE_ACCESSIBILITY_OVERLAY` 全屏遮罩盖住（免悬浮窗权限）
2. 拉起官方 App，每 90ms 按包名取官方窗口的根节点，按文本找按钮 → 找到就点
3. 已经进了官方 App 却找不到按钮：6s 时退一级，9.5s 时还没有就重启一次
4. 13s 超时：把官方 App 的界面结构写进应用私有目录（`ui_dump.txt`），设置页可一键复制

第 4 条有个兜底：轮询过程中每 400ms 会把官方 App 的界面结构留一份快照，
所以即使超时那一刻官方窗口刚好被关掉（系统杀进程、用户按了返回），导出的也是几百毫秒前的内容。

## 验证状态（2026-11-08）

没有真车也能验证的部分，已经在 Android 14 无窗口模拟器上跑通：

- 自建了一个包名、按钮文案都和官方 App 一致的 mock（见 `tools/mock-byd/`）
- 成功路径：解锁 149ms / 525ms 命中，上锁、开后备箱同样命中
- 失败路径：点「一键熄火」（mock 里没有这个按钮）→ 6s 退一级、9.5s 重启 → 13s 超时导出界面结构
- 快照兜底：动作进行到第 10s 强杀官方 App，超时仍导出一份带说明的界面结构

## 构建

需要 JDK 17、Android SDK 35、Gradle 8.9：

```bash
gradle assembleDebug
# 产物 app/build/outputs/apk/debug/app-debug.apk
```

`release/` 下的包就是用 debug 签名构建的，升级安装必须用同一份签名。

mock 官方 App 在 `tools/mock-byd/`，包名故意和官方一致，只用于模拟器测试：

```bash
cd tools/mock-byd && gradle assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
